# NutriOptics

>  NutriOptics addresses the everyday problem of nutrition labels being hard to interpret in the context of a person's actual health needs. Instead of expecting users to manually compare sugar, sodium, fat, allergens, and serving details, the app lets them upload a food label image and receive personalized guidance based on their health profile, allergies, and goals. This makes product decisions clearer for users managing conditions such as diabetes, hypertension, heart disease, cholesterol concerns, or general wellness.

>  The project is built with Python and Streamlit for the frontend application, OpenCV and EasyOCR for nutrition label image preprocessing and OCR extraction, NumPy and Pillow for image handling, Plotly for visual health scoring, and the OpenAI API for personalized nutrition analysis. Project dependencies are managed through `requirements.txt`, with local Streamlit configuration stored under `.streamlit`.
